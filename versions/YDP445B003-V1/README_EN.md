## Overview

OSPTEK **4.45″ 480×854 TFT** is a **MIPI** color display module driven by **ST7701S**. Suited to handheld devices, instruments, and portrait HMI.

Spec ID (repository name): `tft-4.45-480x854-mipi-st7701`

Current module version: **YDP445B003-V1**. Electrical and outline details follow [`docs/YDP445B003-V1.pdf`](./docs/YDP445B003-V1.pdf).
